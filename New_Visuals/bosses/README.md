# Boss visual development

Started 2026-10-14. This folder holds versioned boss artwork and presentation
studies. Source images remain separate from runtime exports. Concepts are
review candidates until selected by the user; creating them does not integrate
them into the game.

## Pursuer

The first study is a compact armored ram with broad shoulders and two large
rear engine housings. Material references are the current Hunter and Colossus
sprites in `../enemies/raw/`. The design brief and animation contract are in
[pursuer/BRIEF.md](pursuer/BRIEF.md).

Current review candidate: [Pursuer v2](pursuer/raw/pursuer-v2.png).
Open [the motion study](pursuer/review.html) to inspect idle, dash, volley and
phase lighting. See [review evidence](pursuer/REVIEW.md) for its scope.

Generate and revise through the connected Chrome ChatGPT extension. Use one
chat for Pursuer, attach the actual selected image for every revision, and
preserve all raw versions. Record the chat URL and measured image properties
beside each saved candidate.

Siege Ring and Storm Ring will follow after the first boss establishes a
selected visual direction.
